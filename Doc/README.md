# Portfolio — Julia El Amrani

A personal portfolio built with React, tracing my first year as a student at EPITECH. Inspired by the sea, calm, deep, and always moving forward.

**Live site:** [fuzzy-couscous-2q51l6q.pages.github.io/home](https://fuzzy-couscous-2q51l6q.pages.github.io/home)

---

### Site Structure 

- **Landing page** - Landing page with a catchphrase and a sea-inspired visual
- **About -** Short introduction of myself, academic background, professionals experiences and skills
- **Projects -** Showcase of school projects built during the year
- **This Year -** A reflection on my first year at EPITECH, hackathons, and growth
- **Contact -** Contact form and CV download

---

### Installation

```bash
git clone https://github.com/julia-el-amrani/B-POR-200-REN-1-1-portfolio-1.git
cd B-POR-200-REN-1-1-portfolio-1
npm install
npm run dev
```

The app will be available at `http://localhost:5173`.

### Technologies and Choices

- [React](https://react.dev/) + JSX - Prior knowledge, wanted to explore a little bit more

- [Material UI](https://mui.com/) - Prior knowledge, customizable component library
- [Formspree](https://formspree.io/) - Easy contact form without a backend
